# Yapay Zeka Destekli Eğitim Görseli Üretim Portalı (Linova Teknoloji)

Linova Teknoloji bünyesinde, 1-8. sınıf öğrencileri için Express.js ve yapay zeka modelleri entegre edilerek geliştirilmiş "Metinden Görsel Üreten" web portalı projesidir.

## Teknoloji Yığını
* **Backend Mimarisi:** Node.js, Express.js
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **AI Entegrasyonu:** Hugging Face API (Text-to-Image Models)

## Proje Kapsamı
* **API Entegrasyonu:** Kullanıcıların girdiği metin tabanlı komutlar (prompts), backend üzerinde işlenerek Hugging Face üretken yapay zeka modellerine REST API protokolüyle aktarılır.
* **Asenkron Veri Yönetimi:** Üretilen görsel verileri arayüze asenkron olarak beslenerek öğrencilerin yaratıcılık süreçlerini destekleyen dinamik bir portal deneyimi sunulmuştur.
